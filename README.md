## 📌 About The Project

**Netflix UI Clone** is a frontend development project inspired by modern
streaming platforms.

The project recreates a Netflix-inspired user interface with a dark theme,
responsive layouts, movie/show sections, interactive navigation, and smooth
hover effects.

This project was developed to strengthen my practical skills in:

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- UI/UX Development
- Git & GitHub
- GitHub Pages Deployment

> ⚠️ **Disclaimer:** This project is created strictly for educational and
> portfolio purposes. It is not affiliated with, sponsored by, or endorsed
> by Netflix.
